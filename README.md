# 📌   Overview
This project demonstrates the concepts of Reverse Shell and Bind Shell in an isolated cybersecurity lab environment using Kali Linux and Metasploitable 2. The objective is to understand how shell connections can be established between two systems, how network connections appear during the process, and how defenders can identify suspicious shell activity through network and traffic analysis. The project also covers basic detection indicators, security risks, and mitigation techniques associated with unauthorized shell connections.
